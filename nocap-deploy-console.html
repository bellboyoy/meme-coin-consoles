2 · Metadata URI

Must be 200 JSON, name/symbol NOCAP, with description, image and an extensions object. The Check URI button rejects PLACEHOLDER / TEST NETWORK on mainnet. Press Check URI.

Step A · Create the mint

Creates a new SPL Token mint (classic Token program) with 9 decimals, mint authority = your wallet, freeze authority = none (explicitly unset). Supply stays 0. A fresh mint keypair is generated in this page just to sign its own creation.
Cost ≈ 0.0010668 SOL rent + 0.00001 SOL fees (2 signatures).
Mint: —

Step B · Create Metaplex metadata

Creates the Metaplex Token Metadata account for the mint: name NOCAP, symbol NOCAP, the URI above, royalty 0, token standard Fungible, mutable (you can add links later), update authority = your wallet.
Cost ≈ 0.0037338 SOL rent + 0.01 SOL Metaplex protocol fee + 0.000005 SOL fee.

Step C · Create your token account and mint the full supply

Creates your associated token account and mints exactly 1,000,000,000 NOCAP (1,000,000,000,000,000,000 base units) into it, in one transaction. Refuses if supply isn't 0. Does not revoke the mint authority (separate, optional step).
Cost ≈ 0.00148844 SOL rent + 0.000005 SOL fee.

Step D (optional, later) · Revoke mint authority

Irreversible. Sets the mint authority to none, so no more NOCAP can ever be minted. Supply is fixed at exactly 1,000,000,000. Do this only after Step C is verified, and before creating a liquidity pool. The page re-reads on-chain supply and refuses unless it is exactly 1,000,000,000. "Simulate" is free and sends nothing.
Cost ≈ 0.000005 SOL fee.
