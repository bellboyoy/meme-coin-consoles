# Meme coin consoles

Public, browser-only deploy consoles. No private keys or secrets are stored in this repository.

- [NOCAP deploy console](nocap-deploy-console.html)
- On a phone, open the console inside the Phantom in-app browser (use the **Open in Phantom** button on the [home page](index.html)).

The pages only contain public metadata URIs, public RPC defaults, and the public expected deployer wallet address.
